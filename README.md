# That Single Thing

Muchos carriles, una sola tarea. Organiza tus frentes de vida en carriles con colas de tareas y asígnalos a bloques de la semana; la app sube al centro una única cosa que hacer.

## Desarrollo

```bash
npm install
npm run dev
```

Abre http://localhost:3000.

## Estructura

- `src/app` — aplicación Next.js (App Router)
- `docs/prototype` — prototipo conceptual en HTML

## Stack

Next.js · TypeScript · Tailwind CSS · Supabase (próximamente)
